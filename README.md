# DTV
EQ2 Descent to Val'Zyroth (DTV) cast stacks - live, Lv 135

Each pack (.zip) holds the stack twice, plus the class's AA build when it has one:
- `EQ2Save_Hub_DTV_<Class>.xml` for the old OgreBot
- `New OgreBot/EQ2Save_Hub_DTV_<Class>.json` for the new OgreBot
- `Namehere_DTV_<Class>.aa`, the AA build

`How to install.txt` inside each pack says the same as this page.

**New OgreBot:** copy the `.json` into `C:\Program Files (x86)\InnerSpace\Scripts\OgreSave\EQ2\OgreBot\Profiles\Import`,
then OgreBot's **Admin** tab: **Refresh List**, click it under **Profiles you can import**, **Import Profile**.

**Old OgreBot:** copy the `.xml` into `C:\Program Files (x86)\InnerSpace\Scripts\EQ2OgreBot\Save\ProfilesToImport`,
then OgreBot's **Admin** tab: **Refresh**, then **Import Profile**.

**With ISXJQB** (new OgreBot): type `jb csimport DTV` in game; it takes your class's stack from isxjhub.com and imports it for you.

**AA build:** put the `.aa` in your EverQuest II folder named `<your character>_<build name>.aa`
(the AA window lists the files that start with your character's name), then **Load** it in the game's AA window.

InnerSpace installed somewhere else? Use your own InnerSpace folder in the paths above.
More on [isxjhub.com](https://isxjhub.com).
